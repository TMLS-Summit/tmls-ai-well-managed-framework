# Section IV. Suggested evaluation criteria

## AI Strategy: Metrics by Step

### Step 1: Establish Company-Wide Vision
- % of AI initiatives mapped to top-level business objectives
- No. of business units actively contributing to AI roadmap (top-down + bottom-up participation rate)
- Idea-to-pilot conversion rate (submitted ideas → approved use cases)
- Cross-functional engagement index (e.g., attendance in AI workshops / hackathons)
- Strategic alignment score (exec assessment of AI portfolio fit vs company priorities)

### Step 2: Select Use Cases (MVP & Early Wins)
- Expected ROI per use case (revenue lift, cost reduction, risk reduction)
- Feasibility score distribution (data readiness + technical + operational readiness)
- Time-to-MVP (idea approval → production pilot)
- % of use cases successfully deployed in MVP phase
- Reuse potential index (# of downstream applications per model/use case)

### Step 3: AI Ethics and Governance
- % of AI systems passing governance/compliance review pre-deployment
- Number of high/critical risk incidents (bias, privacy, security breaches)
- Time to approve or reject AI models (governance cycle time)
- % workforce trained in responsible AI practices
- Audit coverage rate (models or systems reviewed per quarter/year)

### Step 4: Measure and Track Progress
- Model performance score (accuracy, F1, AUC, or task-specific metric)
- Model drift rate (% of models showing degradation over time)
- System reliability (uptime, latency, failure rate)
- User adoption rate (active users / target users)
- Business impact realization (% of projected ROI actually achieved)

## Data Strategy: Metrics by Step

### Step 1: Current State & Future State Definition
- % of critical business domains mapped to data assets
- Data maturity score by domain (current vs target gap)
- Stakeholder alignment score (survey-based consensus on data vision)
- No. of documented data gaps blocking AI use cases
- Roadmap completion rate (planned vs defined data initiatives)

### Step 2: Data Assessment
- Data quality score (completeness, accuracy, consistency, timeliness)
- % of datasets meeting readiness threshold for AI use cases
- Data accessibility score (API availability, latency, permissions)
- No. of critical data issues identified per domain
- Bias / representativeness risk score per dataset

### Step 3: Data Collection, ETL & Management
- Data pipeline success rate (% successful runs)
- Data freshness latency (time from source → availability)
- Time-to-data for new use case (onboarding speed)
- % of datasets with full lineage + versioning coverage
- ETL cost per GB / per pipeline run

### Step 4: Data Governance
- % of data assets with assigned owner/steward
- Policy compliance rate (privacy, retention, access rules)
- Number of data quality incidents (breaks, inconsistencies)
- Audit pass rate (internal/external audits)
- % of datasets classified and catalogued

### Step 5: Analytics, Models & Insights
- Model accuracy / predictive performance by use case
- Insight adoption rate (dashboards or APIs actively used)
- Feature reuse rate (% reused across models)
- Time-to-insight (data → decision-ready output)
- Forecast accuracy / decision uplift (vs baseline decisions)

### Step 6: Decision-Making & Iteration Loop
- Decision cycle time (data insight → business action)
- % of models/data products updated based on feedback
- Backlog velocity (items resolved per sprint/quarter)
- User feedback incorporation rate
- Retraining/refresh frequency adherence

### Step 7: Data Culture & Organizational Enablement
- Data literacy score (training assessment results)
- % of employees actively using self-service data tools
- Data-driven decision adoption rate (survey + behavioral tracking)
- Number of active Data Champions per business unit
- Reduction in central data team dependency (tickets per user / BU)
